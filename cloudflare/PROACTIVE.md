# 声笺主动消息部署（前端 v0.5.5 / 后台 1.2.0）

GitHub Actions 在原 Worker 上部署，保留原 MEMORY_DB、ADMIN_TOKEN、OAuth 连接和已存在的推送密钥。
部署配置 proactive=true 时，仅为缺少的 CONFIG_ENCRYPTION_KEY 与 VAPID 公私钥自动生成随机值，
直接随 Cloudflare Worker 上传；不写入仓库、Actions Secrets、日志或聊天。
存在的密钥不会轮换。若 VAPID 只剩半套则停止，避免悄悄破坏订阅。
VAPID_SUBJECT 使用本 Worker HTTPS 地址。每五分钟 Cron 自动配置并读回验证，保留其他 Cron。

用户只需要：
1. 用支持 Web Push 的 Chrome 打开原声笺地址，看到 v0.5.5。建议添加到主屏幕。
2. 选中需要主动联系的角色。工具/共享记忆库中保存自己的服务根地址、云角色 ID 和角色密钥。
   单纯主动消息不要求开启记忆工具，不要使用管理员密钥。
3. 侧栏 → 角色空间 → 主动消息/来电。允许主动联系；选“只发消息”，
   触发选“连续一段时间没互动”，120 分钟，免打扰 23:00—09:00。
   时区采用手机保存时的时区；手机应为 Asia/Shanghai。
4. 展开“网页关闭后的云端联系”，检查云端连接，勾选必要设定与模型密钥提交授权，点“开启/更新云端联系”。
   模型密钥只在用户自己配置的后台加密保存，生成消息会使用该模型的 API 额度。
5. 点“授权此设备的通知”并允许系统权限，再点“发测试通知”。测试只测通知，不调用模型。
   手机出现通知后，点开检查角色及云端同步是否正确。测试推送服务接受不保证设备显示。

未互动计时记录此角色页面的真实操作/发消息，不把定时轮询、记忆搜索或模型生成当成用户活动。
同一段离开只生成一次消息；回来后重新计时。旧设备上传较早时间不会回拨服务器计时。
生成期间用户返回会取消过时问候；免打扰也约束延迟通知重试。
后台每五分钟检查，Cloudflare Cron 配置传播可能需要数分钟。
每角色每日默认最多2次模型尝试，后台所有角色合计每天最多6次（UTC）；skip/失败也计额度。

关闭：点击“关闭云端联系并移除云端模型密钥”，会停用并删除订阅，记忆库和聊天保留。
手机系统省电、禁用通知、强制停止浏览器和网络可能延迟投递；网页通知不是系统电话。
本地已验证 SQL、加密、VAPID、通知解密和前端接收；真实手机权限和送达需要用户完成最后一步。
